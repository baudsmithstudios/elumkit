## [0.1.0] - 2026-04-28

Initial public release.

### Added

- HTML-first component contract for plain HTML, Eleventy, and server-rendered templates
- Token-driven core CSS with `clerestory`, `iron`, and `forge` themes
- Component styles for buttons, form controls, cards, alerts, badges, status labels, system bars, metrics, meters, data lists, and data tables
- Copyable semantic markup snippets for the v0.1 component set
- Static playground for visual review across themes and critical states
- Documentation for plain HTML usage, Eleventy usage, component markup, and theming
- Node test runner specs for the public CSS, docs, examples, and image asset contracts
