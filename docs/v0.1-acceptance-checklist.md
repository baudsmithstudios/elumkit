# v0.1 Acceptance Checklist

Status: Draft  
Date: 2026-04-20

Use this checklist as the release gate for the lean MVP.

## Global gates

- [ ] Keyboard-only flow works for every interactive element in the MVP examples.
- [ ] Visible `:focus-visible` indicator is present in both light and dark themes.
- [ ] Reduced-motion preferences are respected.
- [ ] WCAG 2.2 AA contrast is validated for core states (default, hover, focus, disabled, invalid).
- [ ] Semantic HTML is used first; custom ARIA is only added when native semantics are insufficient.
- [ ] Mobile viewport (`<= 390px`) remains readable without horizontal scrolling for core examples.

## Component gates

### Button

- [ ] Default and primary variants render with clear affordances.
- [ ] `:disabled` state is visually obvious.
- [ ] Focus ring is visible on keyboard focus.

### Input

- [ ] Label association is documented and shown in examples.
- [ ] Placeholder and entered text are both readable.
- [ ] Invalid state hook exists (`[aria-invalid="true"]`).
- [ ] Disabled state hook exists (`:disabled`).

### Textarea

- [ ] Label association is documented and shown in examples.
- [ ] Invalid state hook exists (`[aria-invalid="true"]`).
- [ ] Disabled state hook exists (`:disabled`).

### Select

- [ ] Label association is documented and shown in examples.
- [ ] Invalid state hook exists (`[aria-invalid="true"]`).
- [ ] Disabled state hook exists (`:disabled`).

### Checkbox

- [ ] Label click target toggles the control.
- [ ] Disabled state remains readable and visually distinct.

### Radio Group

- [ ] Group uses `fieldset` and `legend` in examples.
- [ ] Keyboard behavior works with native radio semantics.
- [ ] Disabled state remains readable and visually distinct.

### Card

- [ ] Title and supporting text hierarchy are clear.
- [ ] Spacing supports dense but readable content blocks.

### Alert

- [ ] Tone hooks exist for `success`, `warn`, and `error`.
- [ ] Example includes live region guidance (`role="status"` or `aria-live`) where relevant.

### Badge

- [ ] Compact status label is readable in both themes.
- [ ] Accent tone is distinguishable from default tone.
