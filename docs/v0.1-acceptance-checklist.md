# v0.1 Acceptance Checklist

Status: Draft  
Date: 2026-04-20

Use this checklist as the release gate for the lean MVP.

## Global gates

- [x] Keyboard-only flow works for every interactive element in the MVP examples.
- [x] Visible `:focus-visible` indicator is present in both light and dark themes.
- [x] Reduced-motion preferences are respected.
- [x] WCAG 2.2 AA contrast is validated for core states (default, hover, focus, disabled, invalid).
- [x] Semantic HTML is used first; custom ARIA is only added when native semantics are insufficient.
- [x] Mobile viewport (`<= 390px`) remains readable without horizontal scrolling for core examples.

## Component gates

### Button

- [x] Default and primary variants render with clear affordances.
- [x] `:disabled` state is visually obvious.
- [x] Focus ring is visible on keyboard focus.

### Input

- [x] Label association is documented and shown in examples.
- [x] Placeholder and entered text are both readable.
- [x] Invalid state hook exists (`[aria-invalid="true"]`).
- [x] Disabled state hook exists (`:disabled`).

### Textarea

- [x] Label association is documented and shown in examples.
- [x] Invalid state hook exists (`[aria-invalid="true"]`).
- [x] Disabled state hook exists (`:disabled`).

### Select

- [x] Label association is documented and shown in examples.
- [x] Invalid state hook exists (`[aria-invalid="true"]`).
- [x] Disabled state hook exists (`:disabled`).

### Checkbox

- [x] Label click target toggles the control.
- [x] Disabled state remains readable and visually distinct.

### Radio Group

- [x] Group uses `fieldset` and `legend` in examples.
- [x] Keyboard behavior works with native radio semantics.
- [x] Disabled state remains readable and visually distinct.

### Card

- [x] Title and supporting text hierarchy are clear.
- [x] Spacing supports dense but readable content blocks.

### Alert

- [x] Tone hooks exist for `success`, `warn`, and `error`.
- [x] Example includes live region guidance (`role="status"` or `aria-live`) where relevant.

### Badge

- [x] Compact status label is readable in both themes.
- [x] Accent tone is distinguishable from default tone.

### Status Bar

- [x] Compact key/value items wrap cleanly on narrow screens.
- [x] Primary brand label is visually distinct without relying on novelty terminal effects.

### Metrics

- [x] Labels, values, and units align predictably for telemetry-style content.
- [x] Numeric values use tabular figures for stable scanning.

### Meter

- [x] Meter examples include `role="meter"` with value bounds.
- [x] Fill tones exist for success, warning, and error states.
