# Security Policy

ElumKit is a small, early-stage project made of CSS, static HTML examples, and documentation.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub's private vulnerability reporting from the repository Security tab.

## Scope

Security reports are most useful when they affect code shipped by this repository, generated release artifacts, or future tooling such as a source-copy CLI.

General styling issues, accessibility bugs, and documentation mistakes should be reported as regular issues.
