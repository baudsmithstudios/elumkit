# core-js

Optional progressive-enhancement scripts. Copy the source and own it, like the CSS.

## tabs.js

Enhances `.elum-tabs[role="tablist"]` into an accessible tabset: reveals the hidden tablist, adds the panel roles and makes panels focusable, roving focus, arrow/Home/End keys, manual activation. Auto-inits every tablist.

```html
<script src="/assets/elumkit/tabs.js" defer></script>
```

Without it, the tablist stays hidden and all panels stay visible.
